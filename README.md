# PS5 Streaming Setup — Telegram Mini App

Interactive 3D model (Three.js) of a one-monitor PS5 streaming setup, built to run as a Telegram Mini App.

- `index.html` — the whole app (Three.js r128 and the Telegram Web App SDK load from CDNs)
- Served via GitHub Pages; that HTTPS URL is what goes into @BotFather (Menu Button or `/newapp`)
